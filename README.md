## 📖 プロジェクト概要

『**パラレル・ジャパニア：クロニクル 〜失われた人権の180分〜**』は、中学3年「公民」および高校「公共」の単元（日本国憲法・基本的人権）に対応した、**428型（タイムライン連鎖群像劇）サウンドノベルゲーム教材**です。

基本的人権が剥奪された架空の統治都市「パラレル・ジャパニア」を舞台に、異なる立場にある3人の主人公の選択が互いの運命とタイムラインにリアルタイムで干渉し合います。「人権が存在しないディストピア」を追体験することで、日本国憲法が保障する諸権利や歴史的判例の意義を深く探究・実感できる構造になっています。

## 🎮 主なゲームシステム・機能

1. **428型 タイムライン・マルチサイトシステム**
   - 3人の主人公のタイムライン（10:00〜12:00の180分間）を切り替えながら進行。
   - ある主人公の選択（スロット）が、他主人公の「通行止め（KEEP OUT）」や展開変化・バッドエンドを誘発する因果連鎖エンジン。
2. **逆照射 TIPSシステム（憲法・判例アーカイブ）**
   - シナリオ中のキーワードをクリックすると、対応する日本国憲法の条文（第14条、第18条、第21条、第25条など）や重要判例（北方ジャーナル事件、尊属殺重罰規定違憲判決、朝日訴訟など）の解説モーダルを表示。
3. **完全永続化 セーブ＆ロード（スプレッドシート連携）**
   - 生徒の「カタカナ氏名」と「4桁パスコード」によるログイン・復帰。
   - 通過ノード、獲得フラグ、解放結末数、スロット状態を Google スプレッドシートにリアルタイム保存（`LockService` による排他制御対応）。
4. **Web Audio API によるサウンド演出**
   - 外部音声ファイル不要の動的シンセシス音源による BGM・SE 再生。

## 🚀 デプロイ・利用手順

### 1. clasp による同期
```bash
# 最新コードを取得
clasp pull

# コード修正後、GASプロジェクトへプッシュ
clasp push
```

### 2. Google Apps Script 側の設定
1. スプレッドシートを新規作成または既存シートを指定し、`Code.js` 内の `SPREADSHEET_ID` を設定します。
2. **「デプロイ」 > 「新しいデプロイ」** を選択。
3. 種類を「**ウェブアプリ**」に設定：
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員（または組織内のユーザー）
4. 発行された Web アプリ URL にアクセスすることでプレイ可能です。

## 📚 授業・探究学習での活用イメージ

- **事前学習**: 基本的人権の三大学習分野（自由権・平等権・社会権）の事前講義。
- **ゲームプレイ（約40〜60分）**: 各自タブレット（Chromebook等）でプレイし、エンディング解明やバッドエンド回収を進める。
- **振り返り・ワークショップ**:
  - なぜその選択がバッドエンドを引き起こしたのか？（＝どの日本人権規定が欠落していたためか？）
  - TIPS で閲覧した憲法条文や判例をもとに、現代社会における基本的人権の不可欠性をディスカッション。
