# 428型 タイムブロック進行 & 因果連鎖整合性マニュアル

## 1. 時間軸の全体構造 (180分システム)

ゲームは 10:00 〜 12:00 の 180分間（3大ブロック）で構成されます。

| タイムブロック | 時間帯 | 目的 / 終端条件 | 各主人公の終端ノード |
| :--- | :--- | :--- | :--- |
| **Hour 1 (第1アワー)** | 10:00 〜 11:00 | 各主人公の状況把握と初期脱出・連携 | `A_1100`, `B_1100`, `C_1100` |
| **Hour 2 (第2アワー)** | 11:00 〜 12:00 | 中央統治タワーへの潜入・管制室到達 | `A_1150`, `B_1150`, `C_1150` |
| **Hour 3 (クライマックス)** | 12:00 | 最上階での直接対峙・全結末分岐 | `CLIMAX_HUB` 〜 各種END |

---

## 2. アワー境界（TO BE CONTINUED）の制御規則

1. **第1アワー終端 (`A_1100`, `B_1100`, `C_1100`)**:
   - 3人全員が11:00に到達するまで、先行した主人公は「一時待機（TO BE CONTINUED）」となり先へ進めません。
   - `TimelineState.getHourProgress().hour1.allClear` が `true` になって初めて Hour 2 への選択肢が解放されます。
2. **第2アワー終端 (`A_1150`, `B_1150`, `C_1150`)**:
   - 3人全員が管制室（東・西・南）に到達し、`A_FREEDOM_DONE`, `B_EQUALITY_DONE`, `C_SOCIAL_DONE` の3フラグが揃うまで `CLIMAX_HUB` へは進入できません。

---

## 3. 因果ロールバック（Causal Rollback）の鉄則

プレイヤーが過去のノード（例：10:00）へJUMPし、別の選択肢を選んだ場合：

```javascript
TimelineState.rollbackFutureSlots(targetNodeId);
```

- **同一主人公の未来のスロット破棄**:
  - 例えばレン（A）が 11:30 から 10:15 へジャンプした場合、`A_` で始まる 10:15 より未来のスロット（`A_1030`, `A_1100` 等）は**即座に全削除**されます。
  - これにより「10:15で別の選択をしたのに、11:30の過去の決定フラグが残っている」という因果矛盾を完全に防止します。
- **他主人公のスロットへの影響**:
  - 他キャラ（B, C）のスロットは削除されませんが、BやCがAの未来スロットを参照している場合、自動的に「未達成（ブロック/KEEP OUT）」へと遷移します。

---

## 4. 循環デッドロック防止のチェックリスト

シナリオ作成・拡張時は、以下の依存関係ループを絶対に作らないよう設計してください。

- ❌ **禁止パターン（循環依存）**:
  - `A_1015` の進行に `B_1030` のフラグが必要
  - かつ、`B_1030` に到達するために `A_1015` のフラグが必要
  - ➡️ **どちらも進めずゲームが詰む**
- ⭕ **安全パターン（時間的前後関係の厳守）**:
  - `A_1015` の選択が `B_1030`（**未来**の時点）をアンロックする。
  - または、Hour 1 内での相互交差は、時間順序（10:00 -> 10:15 -> 10:30 -> 10:45）を崩さない。
